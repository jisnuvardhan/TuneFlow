# Security Policy

## Reporting a Vulnerability

If you discover a potential security vulnerability in TuneFlow, please report
it privately rather than publicly disclosing the issue.

Please include:

- A clear description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Relevant technical details or screenshots

Please do not publicly disclose the vulnerability before it has been reviewed
and addressed.

## Supported Version

The latest public release of TuneFlow is the primary supported version.

## Responsible Disclosure

Security researchers are asked to avoid accessing, modifying, deleting, or
exposing data that does not belong to them while investigating a potential
vulnerability.

Reports will be reviewed in good faith.

## Scope

This policy applies to the official TuneFlow repository maintained by
Jisnu Vardhan.
